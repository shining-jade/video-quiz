# 영상 퀴즈 — 실시간 진행 도구

### 👉 https://shining-jade.github.io/video-quiz/

교사가 교실 화면에서 유튜브 영상을 재생하면 미리 지정한 타임코드에 퀴즈가 자동으로 뜨고,
학생들은 각자 폰으로 반 코드만 입력해 **그 순간의 문항만** 푸는 웹 도구입니다.

**콘텐츠(퀴즈 세트)와 진행(반 세션)이 분리**되어 있습니다.
한 선생님이 만든 세트를 링크로 받은 다른 선생님이 각자 반에서 동시에 써도, 반 코드가 달라 응답이 섞이지 않습니다.

정적 HTML과 JavaScript로 동작합니다. 설치나 빌드 과정은 없습니다.

## 저장과 응답 방식

- 퀴즈 편집 화면의 저장 버튼이나 `Ctrl+S`(`Cmd+S`)를 누르면 Firestore에 정식 저장되어 다른 컴퓨터에서도 이어서 편집할 수 있습니다.
- 입력 중인 내용은 현재 브라우저에 임시 초안으로 자동 보관됩니다. 정식 저장 전 초안은 다른 컴퓨터로 옮겨지지 않으며, 새로고침 뒤에는 복구 여부를 묻습니다.
- 학생이 객관식·복수정답·O/X 번호를 누르거나 단답·서술 내용을 입력해도 즉시 제출되지 않습니다. `제출하기`를 눌러 확정하며, 제한시간 전에는 `다시 고르기`로 제출을 취소하고 수정할 수 있습니다.
- 제한시간이 끝날 때 선택하거나 입력한 답이 있으면 자동 제출됩니다. 아무 답도 없으면 미제출로 남습니다.
- 교사 화면은 문항별 `참여 · 제출 · 미제출` 인원과 학생 화면과 동기화된 남은 시간 막대를 표시합니다. 정답과 응답 분포는 공개 전까지 숨깁니다.

## Firebase 설정 (한 번만)

이 도구는 **영상 퀴즈 전용 Firebase 프로젝트** `video-quiz-65798`의 Cloud Firestore를 씁니다.

- 데이터베이스 위치: **싱가포르(`asia-southeast1`)**
- 데이터베이스 모드: **프로덕션 모드**
- Google 애널리틱스, Gemini 학습 데이터 수집: **끔**

프로젝트를 새로 구성할 때는 Firebase 콘솔 → **Firestore Database → 데이터베이스 만들기**에서 위치를 `asia-southeast1`로 선택합니다. 위치는 만든 뒤 바꿀 수 없으므로 먼저 확인하세요.

### 1) Firestore 보안 규칙

저장소의 [`firestore.rules`](./firestore.rules)가 운영 규칙의 원본입니다. Firebase 콘솔 → **Firestore Database → 규칙**에 파일 내용을 붙여넣고 **게시**합니다.

- `quiz_sets`, `images/{setId}/q`, `codes`, `sessions`와 모든 세션 하위 컬렉션, `config`, `clock`은 **익명 인증 토큰이 있는 요청만** 읽고 쓸 수 있습니다. 이는 인증 없는 직접 요청을 거부하지만 교사·학생·외부 방문자를 구분하지는 않습니다.
- `quiz_sets` 문서 삭제는 규칙에서 항상 거부합니다. 공유 세트 정리는 삭제 대신 `archived`로 숨깁니다.
- 위에 없는 경로는 Firestore의 기본 거부 동작을 따릅니다.

### 2) 익명 로그인 사용 설정

**✅ 이미 사용 설정 완료.** 30일 지난 익명 계정을 자동 정리하도록도 켜 두었습니다(계정이 쌓이지 않고 할당량에도 잡히지 않습니다). 학생 식별은 익명 계정이 아니라 학년·반·번호로 하므로 자동 삭제되어도 기록에는 영향이 없습니다.

콘솔 → **Authentication → Sign-in method → 익명(Anonymous)** 을 **사용 설정**합니다.

교사도 학생도 **로그인 화면을 거치지 않습니다.** 페이지를 여는 순간 브라우저가 익명 계정을 발급받고, 보안 규칙은 인증 토큰이 있는 요청만 통과시킵니다. 공개된 앱은 누구나 익명 계정을 받을 수 있으므로 익명 인증 자체는 사용자 신원이나 역할을 보장하지 않습니다.

> 이 설정을 안 하면 첫 화면에 *"Firebase에서 익명 로그인이 아직 켜져 있지 않습니다"* 안내가 뜹니다.

### 3) 기존 데이터 이전

기존 Realtime Database에서 운영하던 퀴즈 세트는 기존 사이트의 세트 목록에서 **[📤 파일]**로 JSON을 내보낸 뒤, Firestore 배포본의 세트 목록에서 **[📥 세트 가져오기]**로 가져옵니다. 문항·설정·이미지가 함께 이동합니다.

가져온 직후 원본 데이터를 삭제하지 마세요. Firestore 배포본에서 세트 편집, 이미지, 수업 진행, 학생 응답, 대시보드와 관리자 조회를 확인하고 백업 JSON을 별도로 보관한 뒤 학교의 보관·파기 절차에 따라 원본을 정리합니다. 자세한 절차는 [`FIRESTORE-MIGRATION.md`](./FIRESTORE-MIGRATION.md)에 있습니다.

**현재 기존 사이트 주소:** https://shining-jade.github.io/video-quiz/

Firebase 콘솔 규칙 게시, 기존 세트 이전과 원본 객관식 세트의 로컬·GitHub Pages 다중 창 핵심 흐름 검증을 완료했습니다. 다른 문항 유형·이미지·관리자 흐름은 자동 테스트로만 확인했습니다.

저장소는 [shining-jade/video-quiz](https://github.com/shining-jade/video-quiz) (Public), `main` 브랜치 루트를 Pages가 서비스합니다.

### 수정한 내용을 반영하려면

1. `node --test tests/*.test.js`로 자동 테스트를 통과시킵니다.
2. `firestore.rules`를 Firebase 콘솔에 게시합니다.
3. 바탕화면 `영상퀴즈` 폴더에서 변경을 커밋하고 푸시합니다.

```bash
git add -A && git commit -m "수정 내용" && git push
```

1~2분 뒤 사이트에 반영됩니다. 배포 주소를 새로고침한 뒤 교사 창과 학생 창을 각각 열어 다음을 확인합니다.

- 익명 인증 뒤 홈 화면이 정상적으로 열리는지
- 세트 조회·저장과 이미지 표시가 되는지
- 반 코드 발급, 학생 입장, 문항 열기·제출·정답 공개가 실시간으로 이어지는지
- 두 창의 남은 시간이 1초 이내로 맞는지
- 관리자 조회와 기간 삭제가 정상인지
- Firebase 콘솔의 Firestore 사용량과 권한 거부 오류가 예상 범위인지

> 로컬에서 `index.html` 을 더블클릭해 열어도 동작합니다. 다만 그때 만들어지는 공유 링크는 그 PC에서만 열리는 주소이므로, 실제 수업에는 위 Pages 주소를 쓰세요.

## 사용법

### 1. 퀴즈 세트 만들기 (한 번만, 만드는 사람)

`.../#/make` 로 들어가거나 첫 화면에서 **[퀴즈 세트 만들기]** 를 누릅니다.

1. 제목과 유튜브 주소를 입력합니다. 주소는 `watch?v=`, `youtu.be/`, `/shorts/`, `/embed/` 어떤 형태든 됩니다.
2. 화면이 **왼쪽 영상 / 오른쪽 문항**으로 나뉩니다. 영상을 재생하다가 원하는 지점에서 **[📍 현재 시각으로 문항 추가]** 를 누르면, 그 시각의 문항이 오른쪽에 만들어지고 **질문 칸에 커서까지 들어갑니다.** 바로 타이핑하면 됩니다.

   영상은 스크롤해도 왼쪽에 그대로 붙어 있으므로, 문항을 몇 개를 만들든 영상을 보러 위로 올라갈 일이 없습니다. **진행 설정**은 한 번 정하고 마는 값이라 한 줄로 접혀 있고 [설정 바꾸기]로 펼칩니다.

   가운데 경계선을 **끌어서 영상과 문항 칸의 폭을 바꿀 수 있습니다.** 정한 폭은 그 브라우저에 기억되고, 경계선을 두 번 클릭하면 기본값으로 돌아갑니다.
3. 문항 유형을 고르고 내용을 채웁니다.

| 유형 | 채점 | 설명 |
|---|---|---|
| 객관식 | 자동 | 보기 2~6개, 왼쪽 동그라미로 정답 지정 |
| 복수 정답 | 자동 | 정답을 모두 체크. 학생이 고른 것이 **정확히 같아야** 정답 |
| O · X | 자동 | 보기 문구는 직접 고쳐도 됩니다. 학생 화면에는 큼직한 O·X 로 나옵니다 |
| 단답형 | 자동 | 인정할 표현을 한 줄에 하나씩. 띄어쓰기·대소문자·마침표는 무시하고 비교 |
| 서술형 | **교사** | 수업이 끝난 뒤 대시보드에서 O/X 를 눌러 채점. 그 전에는 미채점으로 집계 |

**이미지**도 문항마다 넣을 수 있습니다. 사진 파일을 올리면 브라우저가 알아서 줄여 저장하고(3MB 사진 → 약 30KB), 외부 이미지 주소를 붙여넣어도 됩니다.
4. **[세트 저장하고 링크 만들기]** → 공유 링크가 나옵니다. 이 링크를 다른 선생님께 전달하세요.

문항이 여러 개가 되면 화면 오른쪽에 **문항 목차**가 뜹니다. 항목을 누르면 그 문항으로 바로 이동하고, 옆의 ▲▼로 순서를 바꿉니다. (화면 너비가 좁으면 자리가 없어 숨겨집니다.)

### 1-2. 이미 만든 세트 다시 쓰기 — `#/sets`

첫 화면의 **[만들어진 세트 목록]** 에서 학교 안에 만들어진 세트를 모두 볼 수 있습니다.

| 버튼 | 하는 일 |
|---|---|
| ▶ 진행 | 그 세트로 바로 우리 반을 시작합니다 |
| ✏️ 편집 | 세트 내용을 고칩니다 (모든 선생님에게 반영됩니다) |
| ⧉ 복제 | **원본은 그대로 두고** 사본을 만들어 우리 반용으로 고쳐 씁니다 |
| 🔗 링크 | 공유 링크를 복사합니다 |
| 🗂 숨기기 | 목록에서만 감춥니다. 기록도 링크도 살아 있고, [숨긴 세트도 보기]로 되돌립니다 |

> 세트 **삭제**는 일부러 막아 두었습니다. 다른 선생님이 공유받아 쓰는 세트를 실수로 없애면 그 반 수업이 중단되기 때문입니다. 정리는 [숨기기]로 하세요.

**진행 설정** (이 세트로 진행하는 모든 반에 공통 적용)

| 설정 | 설명 |
|---|---|
| 정답 공개 시점 | `제출 즉시` / `타이머 종료 후 자동` / `교사가 버튼 누를 때` / `학생에게 공개 안 함` |
| 문항당 응답 제한 시간 | 초 단위. **0이면 무제한** — 교사가 [계속 재생]을 누를 때까지 열려 있습니다. |
| 정답 자동 공개까지 | `타이머` 모드에서 퀴즈가 뜬 뒤 몇 초 후에 정답을 보여줄지 |
| 퀴즈가 뜰 때 영상 | 자동 일시정지 / 계속 재생 |

문항마다 제한 시간을 다르게 주고 싶으면, 각 문항의 *"이 문항만 제한 시간 다르게"* 칸을 채우면 됩니다. 비우면 세트 기본값을 씁니다.

### 2. 수업에서 진행하기 (진행하는 선생님)

1. 공유받은 세트 링크를 교실 컴퓨터에서 엽니다.
2. 반 이름(선택)을 적고 **[🚀 우리 반 시작하기]** → 6자리 반 코드가 발급됩니다.
3. 화면 오른쪽의 **반 코드와 QR** 을 학생들에게 보여줍니다.
4. 영상을 재생합니다. 지정한 시각이 되면 영상이 멈추고 퀴즈가 화면 가득 뜹니다.
   - 공개 전에는 **제출 인원만** 보입니다. 이 화면은 교실 앞에 투사되므로 정답 표시도, 보기별 응답 분포도 감춰 둡니다. (둘 다 답을 알려주는 단서가 됩니다.)
   - **[✅ 정답 공개]** — 그때 정답·분포·해설이 학생 화면과 교실 화면에 함께 뜹니다.
   - 타이머 모드에서는 시간이 차면 교실 화면도 학생 화면과 **같은 순간에** 자동 공개됩니다.
   - **[▶ 계속 재생]** — 퀴즈를 닫고 영상을 이어서 재생합니다.
   - 응답 분포를 미리 보고 싶으면 **대시보드**를 다른 창(두 번째 모니터)에 띄워 두세요.
5. 왼쪽 문항 목록에서 시각을 누르면 그 지점으로 이동하고, **[열기]** 로 영상과 무관하게 문항을 직접 띄울 수도 있습니다.

> 💬 **자막** — 유튜브 자동 생성 자막이 영상 아래를 가리는 경우가 많아 **기본은 꺼져 있습니다.** 선택은 그 브라우저에 기억됩니다.
> 자막을 보고 싶으면 **[💬 자막 허용]** 을 누른 뒤, 플레이어 오른쪽 아래 **⚙(설정) → 자막**에서 원하는 자막을 고르세요.
> (끄는 것은 도구가 확실히 처리하지만, 특정 자막을 켜는 것은 유튜브 쪽 제약으로 영상마다 달라 플레이어 메뉴에 맡깁니다.)
6. 수업이 끝나면 **[진행 종료]** 를 누릅니다. 학생 화면이 종료 안내로 바뀝니다.

**실시간 순위** — 오른쪽 사이드바에 학생별 맞힌 개수와 순위가 실시간으로 쌓입니다. **[🏆 크게 보기]** 를 누르면 교실 화면에 띄우기 좋은 큰 순위표가 뜹니다(1~3등은 메달). 퀴즈가 떠 있을 때도 오버레이의 **[🏆 순위]** 로 바로 볼 수 있습니다. 동점은 같은 등수로 묶이고, 채점 전 서술형은 점수에서 빠집니다.

> 순위표는 교사 화면에만 있습니다. 언제 교실에 띄울지는 선생님이 정하시면 됩니다. 학생 화면에는 자기 순위만 조용히 보입니다.

> 영상을 뒤로 되감으면 지나간 문항이 **다시 발화**합니다. 앞으로 건너뛰면 지나친 문항은 건너뜁니다.

### 3. 학생

1. 첫 화면에서 **[학생 참여하기]** → 6자리 반 코드 입력 (QR을 찍으면 코드가 자동으로 채워집니다)
2. 학년·반·번호·이름을 입력하고 입장 → 대기 화면
3. 선생님이 퀴즈를 열면 자동으로 문항이 뜹니다. 답을 고르면 바로 제출됩니다.
4. 학생 화면에는 **영상이 나오지 않습니다.** 교실 앞 화면을 보게 하기 위한 의도된 동작입니다.
5. 퀴즈 사이사이 대기 화면에 **맞힌 개수 · 남은 문항 · 내 순위**가 보입니다. 정답 공개를 "끝까지 비공개"로 설정한 세트에서는 점수와 순위 대신 제출 개수만 보입니다.

> 학생 화면은 **점수 요약만** 받아 순위를 계산합니다. 다른 학생이 무엇을 골랐는지는 내려받지 않으므로, 개발자도구를 열어도 남의 답을 미리 볼 수 없습니다.

같은 학년·반·번호로 다시 들어오면 같은 학생으로 이어집니다. 새로고침하거나 폰을 바꿔도 이미 낸 답이 유지됩니다.

### 4. 실시간 대시보드 (진행 교사)

진행 화면 상단의 **[📊 대시보드]** — 새 탭으로 열어 두 번째 모니터에 띄워 두면 좋습니다.

- 문항별 선택 분포, 정답률, **미응답자 명단**
- 학생별 O/X 표, 총점, 평균 반응속도 (머리글 클릭으로 정렬)
- **서술형 채점** — 서술형 문항을 펼치면 학생이 쓴 답이 모두 나옵니다. 각 답 오른쪽 **O / X** 를 누르면 점수와 정답률에 바로 반영되고, [되돌리기]로 미채점으로 돌릴 수 있습니다
- 단답형도 펼치면 학생이 실제로 뭐라고 썼는지 그대로 보입니다
- CSV 내려받기 (엑셀에서 한글이 깨지지 않습니다. 텍스트 답안과 미채점 표시 포함)

### 5. 관리자 통합 조회

`.../#/admin` — **기본 비밀번호 `admin1234`**

- 기간·세트·학년·반으로 걸러 **전체 반을 가로질러** 조회
- 진행 기록 / 학생별 누적 / 학년·반 집계 3가지 보기
- 학생 이름을 누르면 개인 누적 이력 (세션별 점수)
- ⚙ 관리 탭에서 **비밀번호 변경**과 **기간 지정 삭제**

> 비밀번호는 반드시 바꾸세요. 변경하면 해시가 `config/app` 문서에 저장되어 **모든 기기에 적용**됩니다.

## 개인정보 처리

이 도구는 **학년·반·번호·이름**과 문항별 응답을 Firebase에 저장합니다. 개인정보 처리에 해당합니다.

- 학생 화면 하단에 수집 항목·목적 고지 문구가 표시됩니다.
- 관리자 화면은 비밀번호로 가려집니다. **공용 PC에서는 반드시 로그아웃하세요.**
- 보관 기간이 지난 자료는 관리자 → ⚙ 관리 → **[이 기간 기록 삭제]** 로 파기합니다. 조회 기간에 걸린 진행 기록·학생 응답·반 코드가 함께 지워지고, 퀴즈 세트 자체는 남습니다.
- 학교 개인정보 보호 방침에 맞춰 보관 기간을 정해 운영하세요.

## Firestore 사용량과 읽기 절감 원칙

Cloud Firestore는 문서 읽기·쓰기·삭제 횟수와 저장량을 기준으로 사용량을 계산합니다. 운영 중에는 [Firebase 콘솔의 사용량 화면](https://console.firebase.google.com/project/video-quiz-65798/usage)을 정기적으로 확인하세요.

- 학생 화면은 `sessions/{sessionId}/meta/live` 문서만 실시간 구독합니다.
- 퀴즈 세트는 입장할 때 한 번 읽고 계속 구독하지 않습니다.
- 학생 응답은 학생별 문서에 모아 다른 학생의 답을 내려받지 않습니다.
- 순위 요약은 문항을 닫을 때 갱신하고, 관리자 전체 조회는 필요할 때만 실행합니다.

이 경계를 넓히면 참가자 수만큼 읽기가 반복될 수 있으므로 새 기능을 추가할 때도 유지해야 합니다.

### 알아 두어야 할 보안 한계

이 도구는 **회원가입·로그인이 없는** 구조입니다. 그 대가로 다음 두 가지 한계가 있습니다. 일반적인 수업 운영에는 문제가 없는 수준이지만, 알고 쓰는 것과 모르고 쓰는 것은 다릅니다.

1. **익명 인증과 관리자 비밀번호는 교사·학생·외부 방문자를 구분하지 못합니다.**
   브라우저에서 확인하는 방식이라, 기술을 아는 사람이 우회할 수 있습니다.
   익명 인증은 인증 없는 직접 요청만 거부합니다. 공개 앱 방문자는 누구나 익명 로그인할 수 있으므로 데이터 규칙상 교사·학생·외부 방문자가 같은 권한을 가집니다.
   실제 접근 제어와 역할 구분이 필요하면 교사 계정(이메일 로그인 등)과 역할 기반 규칙을 도입해야 합니다.

2. **정답이 퀴즈 세트와 함께 저장되므로, 개발자도구를 열 줄 아는 학생은 정답을 미리 볼 수 있습니다.**
   막으려면 정답을 분리해 서버에서 채점해야 하는데, 이 구조에서는 과한 공사입니다.
   현재 구조는 성적에 반영되는 평가가 아니라 수업 중 형성평가 용도로만 쓰기를 권합니다.

## 데이터 구조

```
quiz_sets/{setId}                           퀴즈 세트 문서 (문항 배열과 진행 설정 포함)
images/{setId}/q/{문항번호}                  압축한 문항 이미지 문서
codes/{CODE}                                반 코드 → 세션 역인덱스
sessions/{sessionId}                        반 세션 기본 정보
    meta/live                               현재 문항 신호 (q, openedAt, revealed, limitSec)
    meta/board                              학생별 점수 요약
    students/{학년_반_번호}                  참여 학생
    responses/{학년_반_번호}                 학생 한 명의 문항별 응답
config/app                                  관리자 비밀번호 SHA-256
clock/{sampleId}                            서버 시각 보정용 임시 문서
```

### 타이머가 기기마다 어긋나지 않는 이유

앱이 시작될 때 `clock` 임시 문서에 Firestore 서버 타임스탬프를 쓰고 되읽어 로컬 시계와의 차이를 계산한 뒤 문서를 삭제합니다. 퀴즈를 열 때도 `openedAt`에 서버 타임스탬프를 기록하므로 각 기기가 같은 기준으로 남은 시간을 계산합니다.

> 참고: 이 프로젝트를 만든 PC의 시계는 실제로 서버보다 약 5초 빨랐습니다. 각 기기의 `Date.now()` 를 그대로 썼다면 타이머가 5초 어긋났을 상황입니다.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 첫 화면에 "익명 로그인이 아직 켜져 있지 않습니다" | Authentication → Sign-in method → 익명을 사용 설정하세요. |
| 저장이 안 되고 아무 반응이 없음 | `firestore.rules`가 게시되었는지와 익명 인증 상태를 확인하세요. F12 콘솔에 `permission-denied`가 보이면 규칙 또는 경로가 현재 코드와 맞지 않는 것입니다. |
| 영상이 안 나옴 | 학교 네트워크가 유튜브를 차단했을 수 있습니다. 교사 PC에서 유튜브가 열리는지 확인하세요. |
| 영상이 저절로 재생되지 않음 | 브라우저 정책상 첫 재생은 사람이 눌러야 합니다. 재생 버튼을 한 번 눌러 주세요. |
| 자막이 그래도 뜬다 | 광고가 재생되는 동안에는 자막 제어가 먹지 않습니다. 광고가 끝나면 꺼집니다. 그래도 남아 있으면 유튜브 플레이어의 ⚙(설정) → 자막 → 사용 안 함을 한 번 눌러 주세요. 유튜브가 그 브라우저에 기억합니다. |
| 학생이 반 코드를 넣어도 "그런 반 코드가 없습니다" | 코드는 대소문자 구분 없이 6자리입니다. `0/O`, `1/I` 는 애초에 코드에 쓰지 않으므로 헷갈리면 다시 확인하세요. 진행을 종료한 반의 코드도 그대로 유효합니다. |
| 학생 화면에 퀴즈가 안 뜸 | 학생과 교사가 **같은 반 코드**인지 확인하세요. 다른 선생님의 반 코드로 들어가면 그 반 신호만 받습니다. |
| QR이 안 보임 | QR 라이브러리를 못 불러온 경우입니다. 아래 참여 주소를 불러 주거나 코드를 직접 입력하게 하세요. |

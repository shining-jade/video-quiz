# 편집 이력·문항 재정렬·퀴즈 발화·전체화면 개선 설계

## 목표

영상 퀴즈 편집과 교사 진행 화면의 다섯 문제를 함께 해결한다.

1. 편집 중 일반적인 `Ctrl+Z` 실행 취소와 다시 실행을 제공한다.
2. 문항 제목 버블을 드래그해 같은 영상 또는 다른 영상으로 옮긴다.
3. YouTube 재생 시각·seek와 퀴즈 발화 시각을 같은 기준으로 맞춘다.
4. `계속 재생` 뒤 같은 퀴즈가 즉시 반복되는 현상을 없앤다.
5. 일반 화면·전체화면·CSS 대체 전체화면에서 영상과 퀴즈 크기를 안정적으로 맞춘다.

기존 Firestore `videos[]` 데이터 모델, 세션 snapshot, 이미지 저장 원자성, 학생 응답 구조는 유지한다.

## 접근 방식

기존 화면 전체를 재작성하지 않는다. 대신 다음 세 책임을 독립적인 순수 상태 모듈로 분리하고 현재 UI에 연결한다.

- 편집 이력: 현재 편집 상태의 snapshot, undo/redo stack, 저장 기준점
- 문항 재정렬: 동일 영상·교차 영상 이동, 상대 시각 변환, 이미지 키 재매핑
- 퀴즈 발화: 재생·seek·되감기·계속 재생을 구분하는 문항별 상태

레이아웃은 기존 `#pl-stage`, player, overlay, timeline 구조를 유지하면서 viewport 기반 CSS와 한 개의 재계산 함수로 정규화한다.

## 편집 이력과 단축키

- 최근 50개 사용자 편집 상태를 보관한다.
- 문항·영상 추가/삭제/복사/이동, 시간, 질문·선택지·해설, 영상 범위 등 저장 데이터에 영향을 주는 변경을 이력에 넣는다.
- focus, preview 재생 위치, overlay 열림 같은 일시 UI 상태는 이력에 넣지 않는다.
- 연속 텍스트 입력은 같은 필드에서 짧은 시간 안에 발생하면 하나의 undo 단계로 합친다.
- `Ctrl+Z`는 실행 취소, `Ctrl+Shift+Z`와 `Ctrl+Y`는 다시 실행이다.
- 화면 버튼도 같은 명령을 호출하며, stack이 비면 비활성화한다.
- 저장 성공 후 현재 상태를 새 기준점으로 삼고 undo/redo stack을 비운다. 저장 실패 시 이력을 유지한다.
- `Ctrl+S`는 브라우저 기본 저장을 `preventDefault()`로 막고 현재 스크롤·포커스를 변경하지 않은 채 기존 저장 경로를 호출한다.
- 저장 상태는 viewport 우측 상단 고정 알림으로 `저장 중`, `저장 완료`, `저장 실패`를 표시한다. 알림은 문서 흐름을 바꾸지 않는다.
- 입력 중 단축키, IME 조합, 권한 상실, 화면 cleanup 뒤 늦은 저장 완료를 테스트한다.

## 문항 제목 버블과 재정렬

- 각 영상 카드의 문제 타임라인 아래에 `전역 번호 · 짧은 질문 제목 · 원본 시각` 버블 목록을 표시한다.
- 긴 제목은 한 줄 말줄임 처리하고 전체 제목은 접근 가능한 label/title로 제공한다.
- 버블은 pointer drag-and-drop으로 같은 영상 안과 다른 영상 카드 사이에서 이동한다.
- drag 중 목표 영상과 삽입 위치를 명확히 표시한다.
- 키보드·터치 대체 수단으로 `위`, `아래`, `이전 영상`, `다음 영상` 명령을 제공한다.
- 다른 영상으로 옮길 때 기존 영상 구간에서의 상대 위치를 계산해 새 영상 구간의 같은 비율로 문항 시각을 변환한다. 결과는 새 구간 안으로 clamp한다.
- 문항 객체와 이미지 데이터를 함께 재정렬하고 canonical 이미지 키 `v{videoIndex}q{questionIndex}`를 다시 만든다.
- 저장은 기존 부모+이미지 원자 경로를 사용한다. 실패하면 이전 구조와 이미지 키를 유지한다.
- 재정렬은 한 번의 undo 단계이며 undo/redo가 문항, 시각, 이미지 대응을 모두 복원한다.

## 퀴즈 발화 상태 엔진

모든 문항 시간은 원본 YouTube 영상의 절대 초를 기준으로 저장·비교한다. 영상 `start`와 `end`는 표시 구간일 뿐 별도의 상대 문항 시간을 만들지 않는다.

문항별 런타임 상태는 최소한 다음을 구분한다.

- `upcoming`: 아직 발화하지 않음
- `queued`: 같은 tick 또는 다른 열린 문항 때문에 대기 중
- `open`: 현재 퀴즈 overlay에 표시 중
- `completed`: 계속 재생으로 닫혀 현재 통과에서는 다시 열지 않음
- `rearmed`: 문항 시각보다 1초 이상 뒤로 이동해 다시 발화 가능

동작 규칙:

- 자연 재생으로 문항 시각을 통과하거나 seek 결과가 문항 시각에 도달하면 문항을 queue에 넣는다.
- 큰 forward seek는 통과한 문항을 시간·전역 번호 순으로 queue에 넣되 한 번에 하나만 연다.
- `계속 재생`은 현재 문항을 `completed`로 만든 뒤 overlay, dim class, timer, board 상태를 정리하고 영상을 재생한다.
- 계속 재생 직후 동일 시각 tick은 completed 문항을 다시 queue에 넣지 않는다.
- 문항 시각보다 1초 이상 앞쪽으로 seek한 뒤 다시 통과하면 해당 문항만 재무장한다.
- 영상 변경 시 다른 영상의 문항 상태와 queue가 섞이지 않는다.
- 같은 시각의 여러 문항은 전역 번호 순서대로 각각 한 번 처리한다.
- player의 currentTime, 문항 marker, 하단 상태 문구는 동일한 시간 정규화 함수를 사용한다.

## 전체화면 레이아웃

- `#pl-stage`를 전체화면의 유일한 기준 컨테이너로 유지한다.
- 영상은 일반 화면과 Fullscreen API/CSS fallback 모두 중앙 16:9 비율을 유지한다.
- overlay는 stage 중앙에 배치하고 viewport 안전 여백을 적용한다.
- 퀴즈 최대 폭과 높이는 stage 크기의 clamp 값으로 계산한다. 내용이 길면 overlay 내부 본문만 스크롤한다.
- 타이머·상단 참여 상태·하단 진행 버튼은 고정 영역으로 유지하고 본문 스크롤에 휩쓸리지 않는다.
- 하단 퀴즈 타임라인은 overlay와 겹치지 않는 안전 영역에 둔다.
- `fullscreenchange`, CSS fallback 진입·해제, resize/orientation change 때 같은 재계산 함수를 호출한다.
- 전체화면 해제 시 fullscreen 전용 inline style/class와 scroll lock을 모두 제거한다.
- `prefers-reduced-motion`에서는 크기 전환 애니메이션을 줄인다.

## 오류 처리와 안전성

- 저장 중 권한 상실은 기존 JSON 백업·편집 종료 흐름을 유지한다.
- undo/redo snapshot이 손상되면 해당 이력만 폐기하고 현재 편집 상태를 유지한다.
- drag 취소나 잘못된 drop은 데이터를 변경하지 않는다.
- YouTube API가 currentTime을 주지 못하면 발화 상태를 변경하지 않고 다음 tick에 재시도한다.
- overlay 정리와 재생 재개 중 실패하면 문항을 completed로 확정하지 않아 명시 재시도가 가능하게 한다.
- 화면 cleanup 뒤의 timer, promise, player callback은 state identity를 확인하고 새 화면을 변경하지 않는다.

## 테스트와 수용 기준

순수 단위 테스트:

- 50단계 undo/redo, coalescing, 저장 성공/실패 기준점
- 같은 영상·교차 영상 재정렬과 상대 시각 변환
- 이미지 키 재매핑과 undo/redo round trip
- 자연 재생, forward seek, backward rearm, continue 직후 반복 방지, 같은 시각 queue
- 시간 정규화와 시작·종료 구간 marker 일치

DOM/회귀 테스트:

- 단축키가 스크롤·포커스를 바꾸지 않고 고정 저장 알림을 표시
- stale async callback이 다른 화면을 다시 렌더하지 않음
- 버블 drag target과 키보드 대체 명령
- overlay close 후 player 표시·dim 제거·영상 재생
- 일반 화면, Fullscreen API, CSS fallback, fullscreen 해제, 작은 viewport에서 geometry와 내부 scroll

실제 브라우저 수용:

- 문항 marker 근처로 seek해 정확한 문항이 열리는지 확인
- 공개·정답·계속 재생 후 overlay가 사라지고 같은 문항이 반복되지 않는지 확인
- 1초 이상 뒤로 seek한 뒤 다시 통과하면 재출제되는지 확인
- 다른 영상으로 버블을 옮겨 저장·다시 열기·이미지 대응을 확인
- 일반 화면과 전체화면 진입·해제 전후 퀴즈 크기와 조작 버튼을 확인
- 브라우저 제어 도구가 연결되지 않으면 자동 테스트 증거와 미관찰 범위를 명확히 분리한다.

## 비범위

- 저장 완료된 과거 버전의 서버 측 버전 관리
- 여러 사용자의 동시 문서 편집 병합
- 학생 답안 제출 방식 변경
- YouTube 자체 재생 바 UI 수정
- 전체 편집기 또는 진행 화면 프레임워크 재작성

# 다중 영상 퀴즈 플레이리스트 및 중앙 팝업 진행 모드 설계

## 목표

퀴즈 세트 하나에 여러 YouTube 영상을 순서대로 추가하고, 영상마다 재생 시작·종료 구간과 퀴즈를 편집할 수 있게 한다. 교사 전체화면에서는 영상이 항상 화면 중앙에 놓이고, 퀴즈는 좌우 분할이 아니라 영상 위 중앙 카드형 팝업으로 표시된다. 하단에는 YouTube 기본 진행 막대와 별개인 퀴즈 전용 타임라인을 제공한다.

## 데이터 모델

세트의 새 정규 구조는 다음과 같다.

```text
quizSet
├─ title, author, settings, createdAt, updatedAt
└─ videos[]
   ├─ videoUrl
   ├─ videoId
   ├─ startSec
   ├─ endSec
   └─ questions[]
```

- `startSec`는 원본 YouTube 영상 기준 재생 시작 시각이며 기본값은 `0`이다.
- `endSec`는 원본 영상 기준 재생 종료 시각이다. 값이 없으면 원본 영상 끝까지 재생한다.
- 문항의 `t`도 원본 영상 기준 시각으로 저장한다.
- 문항은 자신이 속한 영상의 `questions[]` 안에 저장한다.
- 영상 순서는 `videos[]` 배열 순서와 같다.

## 기존 데이터 호환

- 기존 최상위 `videoUrl`, `videoId`, `questions[]` 형식은 읽을 때 영상 한 개짜리 `videos[]`로 정규화한다.
- 기존 Firestore 문서를 일괄 변경하지 않는다.
- 구형 세트를 편집해 저장하면 신형 `videos[]` 형식으로 저장한다.
- 읽기 경로는 구형과 신형 형식을 모두 지원한다.
- 내보내기, 가져오기, 복제, 로컬 초안, Ctrl+S 저장은 `videos[]`와 영상별 문항을 손실 없이 보존한다.

## 편집 화면

확정된 편집 화면은 영상별 세로 카드형이다.

각 영상 카드에는 다음을 둔다.

- 영상 순서와 제목
- YouTube URL 입력 및 미리보기
- 시작 시간과 종료 시간 직접 입력
- 시작·종료 손잡이가 있는 범위 슬라이더
- 현재 영상의 퀴즈 전용 타임라인
- 영상별 문항 목록
- 영상 복제 및 삭제
- 카드 드래그 순서 변경

카드 아래의 `다음 YouTube 영상 추가`로 새 영상을 이어 붙인다.

### 시간 편집

- `분:초` 직접 입력과 범위 슬라이더 조절은 양방향으로 동기화한다.
- 종료 시간 미입력은 영상 끝을 뜻한다.
- 시작 시간이 종료 시간 이상이면 저장하지 않는다.
- 종료 시간이 원본 길이를 넘으면 원본 길이로 보정한다.
- 영상 메타데이터를 불러오지 못한 동안에는 종료 시간 검증을 보류하고 원인을 안내한다.
- 시작·종료 범위 밖에 있는 문항은 빨간 경고와 함께 목록으로 표시하고 저장을 차단한다.

### 퀴즈 시각 편집

- 퀴즈 시각은 원본 영상 시각으로 표시하고 저장한다.
- 퀴즈 점을 타임라인에서 드래그해 문항 `t`를 변경할 수 있다.
- 타임라인 좌표는 `[startSec, endSec]` 구간을 0~100%로 환산한다.
- 시작 시간을 변경해도 문항은 원본 장면의 시각에 남는다.

## 교사 전체화면 레이아웃

### 영상만 재생 중

- 영상은 화면 정중앙에 놓는다.
- 영상 영역은 원본 비율 16:9를 유지하면서 가용 화면 안에서 최대화한다.
- 좌우에 별도 퀴즈 패널을 두지 않는다.
- 상단 교사 도구와 하단 퀴즈 타임라인은 영상 내용을 과도하게 가리지 않도록 가장자리에 배치한다.

### 퀴즈가 열린 상태

- 기존 영상 플레이어 DOM을 이동하거나 재생성하지 않는다.
- 영상 재생은 기존 정책대로 일시정지하고, 같은 프레임 위에 어두운 반투명 막을 표시한다.
- 화면 정중앙에 둥근 모서리와 그림자가 있는 카드형 팝업을 표시한다.
- 팝업은 데스크톱에서 `width: min(64vw, 960px)`를 사용하고, 900px 미만 화면에서는 좌우 16px 안전 여백을 제외한 너비를 사용한다.
- 문항, 설명, 선택지, 참여·제출·미제출, 타이머를 한 카드 안에 표시한다.
- 팝업은 영상과 좌우로 분할되지 않으며 항상 시각적 중심에 놓인다.
- 정답 공개와 순위도 같은 중앙 카드 영역을 재사용한다.
- `계속 재생`은 중앙 팝업과 어두운 막만 제거하고 같은 플레이어·재생 위치·전체화면을 유지한다.

## 퀴즈 전용 타임라인

- YouTube 기본 진행 막대와 별개의 애플리케이션 타임라인을 하단에 표시한다.
- 현재 영상의 `startSec`를 0%, `endSec` 또는 영상 끝을 100%로 환산한다.
- 현재 재생 위치, 각 퀴즈 위치, 이미 완료한 퀴즈, 다음 퀴즈를 구분해 표시한다.
- 다음 퀴즈까지 남은 시간을 숫자로 함께 표시한다.
- 영상이 바뀌면 타임라인도 다음 영상의 구간과 문항으로 교체한다.
- 교사용 타임라인과 문항 자동 실행은 동일한 원본 영상 시각을 사용한다.

## 여러 영상 재생 흐름

- 첫 영상은 `startSec`부터 재생한다.
- `endSec`에 도달하면 영상을 정지한다.
- 열린 퀴즈가 있으면 먼저 퀴즈를 마무리한다.
- 3초 동안 `다음 영상으로 이동합니다` 안내를 표시한다.
- 다음 영상의 `startSec`부터 자동 재생한다.
- 영상 전환 중 Firestore 세션, 학생, 응답, 점수, 구독은 유지한다.
- 문항 번호는 영상별로 다시 시작하지 않고 세트 전체 기준으로 이어진다.
- 순위와 대시보드는 모든 영상의 문항을 합산한다.

## 마지막 영상 완료

마지막 영상의 종료 시각에는 세션을 자동 종료하지 않는다. 영상을 멈추고 다음 메뉴를 표시한다.

- 모든 영상 재생 완료 안내
- 순위 보기
- 대시보드
- 처음부터 다시 보기
- 진행 종료

Firestore 세션 종료는 교사가 `진행 종료`를 확인한 경우에만 실행한다.

## 오류 처리

- YouTube 영상 로드 실패 시 `다시 시도`와 `다음 영상`을 표시한다.
- 실패한 영상을 임의로 자동 건너뛰지 않는다.
- 유효하지 않은 URL, 시작·종료 역전, 범위 밖 문항은 저장 전에 구체적으로 안내한다.
- 다음 영상 전환 실패가 학생 응답이나 기존 점수를 변경하지 않아야 한다.
- Fullscreen API 거부·미지원 시 기존 CSS 화면 확장 대체 모드를 유지한다.

## 테스트와 완료 조건

- 구형 단일 영상 세트를 `videos[]`로 읽고 다시 저장할 수 있다.
- 신형 다중 영상 세트의 저장, 복제, 가져오기, 내보내기, 초안 복구가 모든 영상을 보존한다.
- 시작·종료 입력과 슬라이더가 동기화된다.
- 퀴즈 시각과 타임라인 좌표가 같은 구간 계산을 사용한다.
- 범위 밖 문항이 저장을 차단한다.
- 영상이 지정 종료 시각에 멈추고 3초 뒤 다음 영상 시작 시각부터 재생된다.
- 마지막 영상 완료가 세션을 종료하지 않는다.
- 영상 전환 후 학생 응답, 제출 상태, 점수, 순위가 유지된다.
- 전체화면에서 영상이 중앙 16:9로 표시된다.
- 퀴즈, 정답, 순위가 영상 위 화면 중앙 카드로 표시된다.
- `계속 재생` 후 같은 플레이어와 재생 위치가 유지된다.
- 교사와 학생의 문항 번호·타이머·응답 상태가 일치한다.
- 실제 브라우저에서 영상 2개, 각기 다른 시작·종료 구간, 학생 5명으로 전체 흐름을 검증한다.

# 해설 이미지와 학생 모바일 미리보기 설계

## 목표

교사가 필요할 때만 해설 편집 영역을 펼쳐 글과 별도 이미지를 등록하고, 정답 공개 뒤 해설 글 아래에 이미지를 표시한다. 편집기 미리보기는 교사용 큰 화면과 학생 모바일 화면을 전환하며 동일한 선택·제출·정답·해설 흐름을 직접 조작할 수 있어야 한다.

## 데이터와 호환성

- 기존 `explain`은 그대로 유지한다.
- 외부 해설 이미지는 `explainImgUrl`, 업로드 여부는 `explainImgUp`으로 저장한다.
- 업로드 원본은 문제 이미지와 같은 images 하위 컬렉션에서 `v{video}q{question}e` 키로 저장하고 편집 모델의 `_explainImg`에 복원한다.
- 기존 `v{video}q{question}` 문제 이미지 키와 숫자형 legacy 키는 변경하지 않는다.
- 공개 전에는 해설 글과 해설 이미지를 모두 숨긴다. 공개 시 `publicAnswer.explainImage`에 허용된 data/https 이미지만 포함한다.

## 편집 UI

- 해설이 비어 있으면 `＋ 해설 추가` 접힘 버튼만 보인다.
- 해설 글이나 이미지가 있으면 해당 문항의 해설 영역을 자동으로 펼친다.
- 펼친 영역에는 해설 글, 해설 이미지 업로드/URL/삭제, `접기`가 있다.
- 문항 제한시간은 같은 행 오른쪽에 두고 해설 영역과 수직 정렬한다.
- 시간 입력과 문항 헤더 버튼은 동일한 제어 높이를 사용한다.

## 미리보기와 실제 화면

- 교사용 미리보기와 학생 모바일 미리보기는 같은 preview core 상태를 사용한다.
- 학생 모바일 모드는 휴대전화 폭의 세로 프레임이며 실제로 보기 선택과 제출이 가능하다.
- 결과 순서는 정답/오답, 해설 글, 해설 이미지다.
- 실제 교사·학생 화면도 공개 후 같은 순서로 해설 이미지를 표시한다.

## 안전성

- 이미지 URL은 http/https만 편집기에 허용하고 공개 데이터는 data:image 또는 https만 허용한다.
- 공개 이미지 크기 제한은 기존 문제 이미지와 같은 380100자다.
- 이미지 카운터와 저장 트랜잭션은 새 해설 이미지 키도 기존 이미지와 동일하게 계산한다.

# 홈 메뉴 반응형 배열 설계

## 목표

홈 화면의 메뉴 카드 4개가 화면 폭을 균형 있게 사용하도록 배열한다. 큰 화면에서는 네 메뉴를 한눈에 비교할 수 있게 한 줄로 표시하고, 화면이 좁아질수록 읽기 좋은 폭을 유지한다.

## 확정된 화면 구성

- 1200px 이상: 메뉴 카드 4개를 한 행의 4열로 표시한다.
- 701px~1199px: 메뉴 카드 4개를 2열 2행으로 표시한다.
- 700px 이하: 메뉴 카드를 한 열로 표시한다.
- 홈 화면 본문은 큰 화면에서 기존 `980px` 제한 대신 `1400px` 폭을 사용할 수 있게 한다.
- 네 카드의 높이는 같은 행 안에서 동일하게 늘어나도록 유지한다.
- 카드 내용, 순서, 링크와 진행 흐름 안내의 문구는 변경하지 않는다.

## 구현 방식

홈 화면의 최상위 래퍼에 기존 `.wide` 변형을 적용한다. `.home-cards`는 기본 4열 그리드로 바꾸고 1200px 및 700px 경계의 미디어 쿼리에서 각각 2열과 1열로 전환한다. 홈 화면 이외의 페이지 폭과 공통 카드 스타일은 건드리지 않는다.

## 검증

- 자동 테스트로 홈 화면에 넓은 래퍼가 적용되고 반응형 CSS 규칙이 포함되는지 확인한다.
- 브라우저에서 넓은 화면의 4열, 중간 화면의 2열, 모바일의 1열을 확인한다.
- 카드 4개의 링크와 표시 순서가 기존과 동일한지 확인한다.
